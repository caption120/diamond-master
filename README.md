**Diamond Master** is a high-performance browser extension tailored for luxury jewelry merchants, e-commerce designers, and digital asset managers. It bypasses dynamic responsive downsampling on enterprise CDNs to inspect and retrieve original, uncompressed studio master photos and 1080p Instagram Reels with maximum visual clarity.

---

## Key Features

* **100% Bit-Exact 4K Master Clarity**: Automatically bypasses lossy WebP conversions and responsive query downscaling (`&width=`, `&crop=`) across:
  * **Shopify & Custom Domains**: Direct retrieval of uncompressed original vendor uploads (900 KB - 3 MB+).
  * **Etsy**: Automatic upscaling to `il_fullxfull.` raw camera files.
  * **Tanishq / Titan / Mia / Fastrack / Zoya**: Direct static disk bypass on Salesforce Commerce Cloud & Akamai Image Manager (`imwidth=2400&impolicy=hq`).
  * **Adobe Scene7, Cloudinary & Imgix**: Automatic stripping of downscale and lossy quality compression filters.
* **Universal 1080p Reel & Video Downloader**: 1-click download of Instagram Reels, Shopify 360-degree turntable spins, and product showcase videos directly from media players.
* **Instagram Carousel Multi-Slide ZIP**: 1-click batch download of all photos and videos in an Instagram carousel post into a single organized ZIP archive.
* **Zero Noise & Clutter Filter**: Advanced engine strictly filters out comment avatars, 150×150 story bubbles, emojis, and dimmed background grid posts.
* **Apple Glassmorphism UI (macOS Tahoe / visionOS Inspired)**:
  * Sleek, frosted acrylic overlays pinned cleanly to media corners without obstructing viewports.
  * 100% vector SVG icons throughout the interface (zero emojis).
* **Slide-Out Media Catalog Drawer**:
  * Real-time keyword filter and resolution chips (`All`, `4K Master`, `HD`, `Reels`, `Tanishq`, `Shopify`, `Etsy`).
  * Dedicated **[Download]** action on every single media card (side panel stays persistently open).
  * Bulk **Download All as ZIP** capability with lossless client-side compression.

## Installation (100% Free - Works on All Chromium Browsers)

You can install and use Diamond Master for free on **Google Chrome, Microsoft Edge, Brave, Opera, and Arc**:

### Quick 3-Step Setup:
1. **Download the latest release:**  
   Download **[`diamond-master-v2.0.0.zip`](https://github.com/caption120/diamond-master/releases/download/v2.0.0/diamond-master-v2.0.0.zip)** from the Releases section.
2. **Extract the ZIP file:**  
   Right-click `diamond-master-v2.0.0.zip` and extract it to a folder on your computer.
3. **Load in Chrome / Edge / Brave:**  
   - Open your browser and navigate to `chrome://extensions/` (or `edge://extensions/` on Microsoft Edge).
   - Toggle **Developer mode** ON (switch in the top-right corner).
   - Click the **"Load unpacked"** button in the top-left corner.
   - Select the extracted folder containing `manifest.json`.
   - **Done!** Diamond Master is active and ready to use.
